  6923→### Form State Sync Pattern (lint-clean)
  6924→
  6925→The sheet's local form state (`values`, `apiVisible`, `deactivateOpen`) needs to reset whenever the operator opens the sheet on a different provider. The initial implementation used `useEffect([provider]) → setValues(...)`, which the project's ESLint config (`react-hooks/set-state-in-effect`) flags as cascading renders. Refactored to React's documented "adjust state during render" pattern (https://react.dev/learn/you-might-not-need-an-effect#adjusting-some-state-when-a-prop-changes):
  6926→```tsx
  6927→const [prevProviderId, setPrevProviderId] = useState(provider?.id);
  6928→if (provider && provider.id !== prevProviderId) {
  6929→  setPrevProviderId(provider.id);
  6930→  setValues(valuesFromProvider(provider));
  6931→  setApiVisible(false);
  6932→  setDeactivateOpen(false);
  6933→}
  6934→```
  6935→This is allowed because React handles setState-during-render specially when guarded by a prop-change condition (it re-renders synchronously without committing, no cascade). Lint now clean.
