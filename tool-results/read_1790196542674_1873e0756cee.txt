   103→### Pattern Applied
   104→
   105→```tsx
   106→import { makeTermResolver, plural } from "@/lib/platform/terminology";
   107→import { usePlatform } from "@/lib/platform/platform-context";
   108→
   109→function Page() {
   110→  const { runtime, tenant } = usePlatform();
   111→  const term = makeTermResolver(tenant);
   112→  // titles & KPI labels use plural(term(...)) or term(...)
   113→  // descriptions & search placeholders use plural(term(...)).toLowerCase() or term(...).toLowerCase()
   114→}
   115→```
   116→
   117→`makeTermResolver(tenant)` returns a `(key: TermKey) => string` — it has NO plural option, so the `plural()` helper from the same module is composed in for plural labels (e.g., `plural(term("trader"))` → "Traders" / "Participants" / "Candidates"). For lowercase description text, `.toLowerCase()` is chained. The destructured `tenant` is the `TenantContext` object whose `terminology` record holds the per-tenant overrides (Alpha: trader=Participant, challenge=Evaluation, payout=Withdrawal; Beta: defaults; Gamma: trader=Candidate, challenge=Assessment, payout=Disbursement; super-admin platform pseudo-tenant: empty record → defaults).
