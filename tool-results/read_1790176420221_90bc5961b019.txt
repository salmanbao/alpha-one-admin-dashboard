     1→# PFaaS Platform — Worklog
     2→
     3→## Project: Prop Firm as a Service (PFaaS) Multi-Tenant Dashboard Platform
     4→
     5→A modular, white-label dashboard platform for prop firms. Single Next.js 16 app
     6→rendering a unified dashboard at `/` with client-side view routing, dynamic
     7→module composition, multi-tenant + multi-role demonstration.
     8→
     9→### Architecture (adapted to single-app Next.js constraint)
    10→
    11→```
    12→src/
    13→├── app/
    14→│   ├── layout.tsx              # root layout, providers
    15→│   ├── page.tsx               # unified dashboard entry (AppShell + DashboardRouter)
    16→│   └── globals.css            # theme tokens, brand variables
    17→├── lib/
    18→│   ├── platform/              # platform foundation
    19→│   │   ├── types.ts           # module SDK, manifests, nav, widgets, tenant, auth, perms
    20→│   │   ├── mock-data.ts       # tenants, users, traders, accounts, challenges, etc.
    21→│   │   ├── module-registry.ts # module registry + runtime
    22→│   │   ├── permission-engine.ts
    23→│   │   ├── navigation-engine.ts
    24→│   │   ├── dashboard-engine.ts
    25→│   │   ├── theme-engine.ts
    26→│   │   └── terminology.ts
    27→│   ├── platform-context.tsx   # TenantProvider, AuthProvider, PlatformProvider
    28→│   └── utils.ts
    29→├── components/
    30→│   ├── shell/                 # AppShell, Sidebar, Topbar, Breadcrumbs, CommandMenu
    31→│   ├── platform/              # guards, dashboard grid, widget container, error boundary
    32→│   └── ui/                    # shadcn/ui (existing)
    33→└── modules/                   # business modules (each self-contained)
    34→    ├── trading/
    35→    ├── challenges/
    36→    ├── risk/
    37→    ├── payouts/
    38→    ├── analytics/
    39→    ├── affiliates/
    40→    ├── accounting/
    41→    ├── marketing/
    42→    ├── crm/
    43→    ├── kyc/
    44→    ├── support/
    45→    └── ai/
    46→```
